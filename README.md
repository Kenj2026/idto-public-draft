**Status:** DRAFT / For Discussion (Proposed / Pre-establishment)

## Fixed (Constitution)
**3 Pillars**
- Error-Correction as an OS
- Recording Intent & Change
- Protocol, not a Platform

**6 Keywords**
- Good-faith by default
- Non-regulatory
- Traceable & auditable
- No rating
- Federated
- Politically neutral
